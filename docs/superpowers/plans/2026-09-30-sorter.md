# 行排序（sorter）实现计划 + vela-pc 迁移路线图

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 ScrollGroupTable 补上「点表头对行排序」能力，作为替换 vela-pc 里 AdvanceTable 的第一个功能。

**Architecture:** 排序状态由组件内部维护（传 `sortedInfo` 则受控），组件据此算出一份「显示顺序」用于渲染、合并计算与编辑定位；组件不改父组件的 `dataSource`，排序结果通过 `sort-change` / `update:sortedInfo` 回传。比较、排序、状态循环全部放在不依赖 Vue 的纯函数模块里。

**Tech Stack:** Vue 2.7.16（Options API）+ Vite 5 + node:test；验证脚本用无头 Chrome 走 CDP。

**Spec:** 本文件第 1 节「迁移路线图」+ 第 2 节设计与接口；无独立 spec 文档（设计在本次对话中确认）。

## Global Constraints

- 组件必须是纯 Vue 2 Options API，不引入 Composition API、不引入任何运行时依赖。
- 组件不修改父组件传入的 `dataSource` / `columns`；内部状态只在本次会话生效，父组件回写 props 后以 props 为准。
- **无缝衔接是硬要求**：页面代码零改动、视觉与交互零差异、必须可一键回滚、已有用户的 localStorage 列宽缓存不能失效。
- 所有算法必须放在 `src/components/table/*.js` 纯函数模块中，并配 `node:test` 单测。
- 每个任务的验证包含三步：`pnpm test`、`pnpm build`、对 dev 与 dist 各跑一次 `.verify/*.mjs` CDP 回归。
- 提交信息用中文，格式 `feat: …` / `fix: …`。

- [ ] **Step 1: 引入纯函数并加 prop / data / computed**

```js
import {
  SORT_ASCEND,
  SORT_DESCEND,
  findColumnByKey,
  nextSortOrder,
  resolveSortInfo,
  sortRows
} from './table/sort.js'

// props
sortedInfo: { type: Object, default: null },

// data
innerSortedInfo: null,
suppressHeaderClick: false,

// computed
activeSortInfo() {
  return resolveSortInfo(this.sortedInfo, this.innerSortedInfo)
},
sortColumn() {
  const info = this.activeSortInfo
  if (!info.columnKey || !info.order) return null
  return findColumnByKey(this.columns, info.columnKey)
},
/** 渲染、合并、编辑统一用这份顺序 */
displayRows() {
  const column = this.sortColumn
  if (!column) return this.dataSource
  return sortRows(this.dataSource, column, this.activeSortInfo.order)
},
```

- [ ] **Step 3: 表头按列渲染排序箭头并响应点击**

```js
sortOrderOf(leaf) {
  const info = this.activeSortInfo
  return info.columnKey === leaf.key ? info.order : null
},
ariaSortOf(leaf) {
  const order = this.sortOrderOf(leaf)
  return order === SORT_ASCEND ? 'ascending' : order === SORT_DESCEND ? 'descending' : 'none'
},
handleHeaderClick(leaf) {
  if (this.suppressHeaderClick) return    // 刚拖完列头，不要顺带触发排序
  if (!leaf.sorter) return
  if (this.editingCell) this.cancelEdit() // 排序会让行移动，先退出编辑

  const info = this.activeSortInfo
  const current = info.columnKey === leaf.key ? info.order : null
  const order = nextSortOrder(current, leaf.sortDirections)
  const nextInfo = { columnKey: order ? leaf.key : null, order }

  if (!this.sortedInfo) this.innerSortedInfo = nextInfo
  this.$emit('update:sortedInfo', nextInfo)
  this.$emit('sort-change', {
    columnKey: nextInfo.columnKey,
    order: nextInfo.order,
    column: leaf,
    dataSource: this.dataSource
  })
},
```

模板有三处表头叶子单元格要改：**分组模式第一行**（变量名是 `cell.leaf`）、**分组模式第二行**（`leaf`）、**无分组模式第一行**（`leaf`）。
三处都加 `:aria-sort="ariaSortOf(那个变量)"`、`:class="[..., { 'sgt-sortable': !!那个变量.sorter }]"`、`@click="handleHeaderClick(那个变量)"`，标题后面加下面的箭头：

```html
<span v-if="cell.leaf.sorter" class="sgt-sorter" :class="{
  'is-ascend': sortOrderOf(cell.leaf) === 'ascend',
  'is-descend': sortOrderOf(cell.leaf) === 'descend'
}"><i class="sgt-sorter-up"></i><i class="sgt-sorter-down"></i></span>
```

并在 `createLeaf` 里带上 `sorter: column.sorter || null`、`sortDirections: column.sortDirections || null`、`defaultSortOrder: column.defaultSortOrder || null`。

- [ ] **Step 3: 编辑时按 record 定位原始下标回写**

```js
finishEdit(cell, value, raw) {
  const { rowIndex, field, leaf } = cell
  const displayRecord = this.displayRows[rowIndex]
  const mergedRowIndexes = spanRowIndexes(this.mergePlan, leaf.key, rowIndex)
  const originalRowIndexes = mergedRowIndexes
    .map((index) => this.dataSource.indexOf(this.displayRows[index]))
    .filter((index) => index >= 0)

  const oldValue = displayRecord ? displayRecord[field] : undefined
  // …unchanged 判断与收尾不变…

  const nextDataSource = this.dataSource.map((item, index) =>
    originalRowIndexes.indexOf(index) >= 0 ? Object.assign({}, item, { [field]: value }) : item
  )

  this.$emit('update:dataSource', nextDataSource)
  this.$emit('cell-change', {
    value, oldValue, record: displayRecord, dataIndex: field, rowIndex,
    column: leaf, mergedRowIndexes, originalRowIndexes, dataSource: nextDataSource
  })
}
```

- **rowKey 是函数且依赖下标** 时，排序会让 key 漂移；本计划不改 key 解析，改为在 README 注明「排序场景请用记录内的唯一字段做 rowKey」。

## 2. F1 设计与接口

```js
{ title: '数量', dataIndex: 'qty', sorter: true }                  // 按 dataIndex 比较
{ title: '客户', dataIndex: 'customer', sorter: (a, b) => number }  // 自定义比较
{ title: '数量', dataIndex: 'qty', sorter: true, sortDirections: ['ascend'] , defaultSortOrder: 'descend' }
```

```js
sortedInfo: { type: Object, default: null }   // { columnKey, order }；传了 = 受控
// 事件
'sort-change'      // { columnKey, order, column, dataSource }
'update:sortedInfo' // 同 payload，供 :sorted-info.sync
```
