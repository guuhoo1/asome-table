# F8 合计行 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对齐老壳的 `summary` / `summaryData` / `summaryRender`：在表体最后渲染一行「合计」，按列取 `summaryData` 的值，分组列跨其子列。

**Architecture:** 核心组件在表体最后加一个 `summary` 插槽（真实渲染，不再像老壳那样 `appendChild` 注入 DOM）；兼容壳负责按老壳规则生成这一行：勾选列占位单元格 + 第一列显示「合计」+ 其余列取 `summaryData[dataIndex || key]` + 分组列 `colspan` = 子列叶子数。

**Tech Stack:** Vue 2.7.16（Options API）+ node:test + Playwright。

**Spec:** 老实现见 `vela-pc/.../draggerTable.vue` 的 `appendSummaryRow()` 与样式（`.summary-row` 背景 `#fafafa`、加粗；`.summary-cell` 红色 `#ff4d4f`、居中；首列左对齐）。

## Global Constraints

- 核心只在表体末尾加一个**可选插槽**，不传时行为完全不变。
- 视觉对齐老壳：最后一行、背景 `#fafafa`、加粗、单元格文字 `#ff4d4f`、居中（首列左对齐）。
- `summaryRender` 兼容老契约（无参、返回 DOM 节点）→ 塞进合计行；返回 VNode / 字符串也支持。
- 验证：`pnpm test`、`pnpm build`、`pnpm test:e2e`；完成后追加 `docs/PROGRESS.md`，全绿合并 main 并推送。

- [x] **Step 1: 写失败的测试（纯逻辑）**

```js
const columns = [
  { key: 'no' },
  { key: 'group-amount', children: [{ dataIndex: 'amount' }, { dataIndex: 'tax' }] },
  { dataIndex: 'status' }
]

test('summaryCellsOf：首列「合计」、分组列跨子列、其余取 summaryData', () => {
  const cells = summaryCellsOf({ columns, summaryData: { no: '-', amount: '¥100', status: '3 条' } })
  assert.deepEqual(cells, [
    { key: 'no', text: '合计', colspan: 1 },
    { key: 'group-amount', text: '¥100', colspan: 2 },
    { key: 'status', text: '3 条', colspan: 1 }
  ])
})

test('summaryCellsOf：有勾选列时先占一格空位', () => {
  const cells = summaryCellsOf({ columns, summaryData: {}, hasSelection: true })
  assert.deepEqual(cells[0], { key: '__selection', text: '', colspan: 1 })
  assert.equal(cells[1].text, '合计')
})
```

- [x] **Step 2: 跑测试确认失败** → **Step 3: 实现 `summary.js`** → **Step 4: 通过**（76 → 78）
- [x] **Step 5: 兼容壳渲染合计行**

```html
<template #summary="{ columns: topColumns }">
  <tr v-if="summary" class="sgt-summary-row atc-summary-row">
    <td
      v-for="cell in summaryCells"
      :key="cell.key"
      class="atc-summary-cell"
      :colspan="cell.colspan"
    >
      <span v-if="cell.host" ref="summaryHost">{{ cell.text }}</span>
      <template v-else>{{ cell.text }}</template>
    </td>
  </tr>
</template>
```

（`summaryRender` 存在时：先渲染 `ref="summaryHost"` 的容器，`mounted/updated` 里把
`summaryRender()` 返回的 DOM 节点塞进去；返回 VNode/字符串则直接替换文本。）
